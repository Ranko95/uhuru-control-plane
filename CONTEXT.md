# Uhuru Control Plane

Словарь коммерческого доступа и Нод Uhuru. Согласован с [доменным словарём проекта](../../uhuru-vpn-plan-v2/CONTEXT.md).

## Language

**Коммерческий доступ (Commercial Access)**:
Правила предоставления Пользователю VPN-доступа по Тарифу через Подписку и Профили доступа. Коммерческое право не гарантирует, что Ноды уже применили разрешение или запрет.
_Avoid_: Billing, Node Readiness

**Пользователь (User)**:
Однозначно идентифицированный системой человек, которому Администратор предоставляет доступ к VPN-сервису. Пользователь не подразумевает наличие аккаунта самообслуживания.
_Avoid_: Account, Customer

**Подписка (Subscription)**:
Единственное ограниченное во времени право Пользователя пользоваться VPN-сервисом. Подписка не является платёжной операцией или ссылкой на конфигурации.
_Avoid_: Plan, Payment, Subscription Link

**Тариф (Plan)**:
Набор коммерческих условий доступа: цена, длительность, условия трафика и допустимое число Профилей доступа. Тариф не является индивидуальным правом Пользователя на доступ.
_Avoid_: Subscription, Payment

**Профиль доступа (Access Profile)**:
Принадлежащий Пользователю независимо отзываемый доступ со своими секретами подключения и получения конфигураций; для замены отозванного Профиля создаётся новый. Один Профиль может использоваться на нескольких физических устройствах.
_Avoid_: Device, Client, Profile Generation

**Ссылка подписки (Subscription Link)**:
Секретная отзывная ссылка одного Профиля доступа для получения его VPN-конфигураций. Она не является самой Подпиской или Секретом подключения.
_Avoid_: Subscription, Protocol Credential, Access Profile

**Конфигурация подключения (Connection Configuration)**:
Набор параметров подключения VPN-клиента с Секретом подключения одного Профиля доступа к одной Ноде. Ссылка подписки предоставляет такие конфигурации для готовых Нод, включённых в выдачу, при разрешённом Желаемом доступе.
_Avoid_: Subscription, Subscription Link, Node Template

**Желаемый доступ (Desired Access)**:
Право Профиля на VPN-доступ, определяемое действующей Подпиской и отсутствием отзыва Профиля. Оно не гарантирует, что Ноды уже применили соответствующее разрешение или запрет.
_Avoid_: Applied Access, Node Status

**Нода (Node)**:
Однозначно идентифицированный VPN-сервер, обслуживающий Профили доступа. Нода не является географической локацией, адресом подключения или управляющим агентом.
_Avoid_: Location, Endpoint, Agent

**Агент Ноды (Node Agent)**:
Локальный исполнитель на Ноде, приводящий её разрешённый состав Профилей доступа к заданному Control Plane и подтверждающий проверенное применение. Агент Ноды отличается от самой Ноды и VPN-клиента Пользователя.
_Avoid_: Node, VPN Client, Control Plane

**Готовность Профиля на Ноде (Profile Readiness)**:
Подтверждённое применение Профиля на конкретной Ноде согласно последним полученным сведениям. Оно не гарантирует текущую сетевую доступность Ноды и не отменяется одной лишь потерей связи с ней.
_Avoid_: Subscription Status, Node Health
