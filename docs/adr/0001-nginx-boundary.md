# Публичный HTTPS на nginx, локальный HTTP для Control Plane

Control Plane размещён с nginx на одном VPS и слушает только `127.0.0.1`: nginx завершает публичный TLS на порту 443 и передаёт запросы приложению по HTTP. Публичными остаются `/agent/v1/sync`, `/s/:secret` и временно `/admin`; Agent сохраняет исходящий HTTPS-запрос с Bearer, а `/admin` — Basic Auth. Так сертификат обслуживается в одном месте, прямой порт приложения закрыт, а действующий протокол синхронизации не меняется. nginx не записывает URL, заголовки и тела запросов в журналы или кэш: ссылки подписки и снимки доступа содержат секреты.
